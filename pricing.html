Frequently Asked Questions

Some useful details before starting a project.

Are these fixed prices?

No. These are estimated ranges. The final price depends on the size of your project and the features you request.

Can I request something outside these packages?

Yes. You can ask about Python applications, Discord bots, automation, and scripts written in other programming languages. Custom work can receive its own quote.

Is hosting included?

Hosting is not automatically included. Hosting providers, domains, databases, and paid APIs may have separate costs.

What if I want extra features later?

Additional features can be discussed separately. Depending on the amount of work involved, they may require an additional fee.

How do I request a project?

Join the DevKaz Discord server and describe your idea. Include the features you need so a suitable price can be discussed.
